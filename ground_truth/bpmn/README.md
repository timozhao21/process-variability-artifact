# Ground-Truth BPMN Specifications

These BPMN files are hand-authored ground-truth specifications for the
synthetic scenarios. They are not discovered models and were not generated by
PM4Py.

The BPMN files document the intended control-flow structure:

- `baseline.bpmn`: happy path only
- `optional.bpmn`: optional request-documents and manual-review branches
- `order.bpmn`: alternative order of `Check` and `Assess`
- `rework.bpmn`: optional one-time rework path with a repeated `Assess`
- `mixed.bpmn`: optional activities, alternative ordering, and one-time rework

The exact finite trace language used by the generator is defined in
`../valid_variants.csv`. The BPMN files should therefore be read as formal
scenario specifications that support the variant table, not as mined output
models.

The source BPMN files intentionally contain the process semantics without BPMN
diagram-interchange layout coordinates. For reviewer-friendly visual inspection,
matching PNG and PDF companions are provided in `../visuals/`. The exact finite
language remains `../valid_variants.csv`.
