# Ground-Truth Declare Specifications

These JSON files are hand-authored ground-truth constraint projections for the
synthetic scenarios. They are not discovered models and were not generated by
PM4Py.

The exact finite trace language used by the generator is defined in
`../valid_variants.csv`. The Declare files document the intended declarative
reading of that trace language with the same family of templates used in the
experiment where possible.

The `mixed.declare.json` file is intentionally a projection rather than an exact
standalone Declare encoding; the exact finite mixed trace language is the
variant table in `../valid_variants.csv`.

Some behavior is easier to state exactly as a finite variant table than as a
small Declare model. For that reason, these files should be read together with
`../valid_variants.csv`, not as replacements for it.

The discovered-model experiment uses the fixed template language documented in
`../../PARAMETER_RATIONALE.md`. These ground-truth JSON files are explanatory
projections and need not list every discovery template; they should not be read
as discovered output or as the exact trace-language oracle.
